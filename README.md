# Rule-Based AI Chatbot 🤖

## About the Project

Sam is a simple, interactive chatbot built using Python. It uses predefined rules and conditional statements to respond to greetings, basic questions, and exit commands.

**Note:** This project is a rule-based chatbot. It does not use machine learning, deep learning, or a trained AI model.

## Features

- Responds to common greetings.
- Answers basic questions about itself.
- Responds to simple questions about Python.
- Provides a help message.
- Supports exit commands such as `bye`, `exit`, and `quit`.
- Handles input regardless of capitalization or surrounding whitespace.

## Technologies Used

- Python 3
- `if`, `elif`, and `else` statements
- `while` loops
- String methods: `lower()` and `strip()`
- User input and console output

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python chatbot.py
```

On some systems, use `python3 chatbot.py` instead.

## Example Conversation

```text
🤖 Sam: Hello! My name is Sam.
You: hello
Sam: Hello! Nice to meet you. 😊
You: what is python
Sam: Python is a beginner-friendly programming language.
You: quit
Sam: Goodbye, friend! Have a great day. 👋
```
